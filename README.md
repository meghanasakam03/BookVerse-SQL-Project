# 📚 BookVerse – Book Management System

## 📌 Project Overview
BookVerse is a database management project developed using MySQL. It is designed to manage book details, customer information, and customer orders efficiently.

## 🛠️ Technologies Used
- MySQL
- MySQL Workbench
- SQL

## 🗄️ Database Information
**Database Name:** `bookverse_db`

### Tables
1. Books
2. Customers
3. Orders

## 📊 Key SQL Concepts
- Database and Table Creation
- Primary Keys and Foreign Keys
- Data Insertion
- SELECT Queries
- WHERE Clause
- JOIN Operations
- Aggregate Functions
- GROUP BY
- ORDER BY

## ▶️ How to Run the Project
1. Download the SQL project file.
2. Open MySQL Workbench.
3. Connect to your MySQL Server.
4. Open the SQL script.
5. Execute the queries.
6. Refresh the Schemas panel to view the database tables.

## 🎯 Project Objective
To understand relational database design, data management, and SQL query operations through a practical Book Management System project.
